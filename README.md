# 🏍️ 24-0 World Superbike Draft

**X-0 Sports Draft template #19** — Draft 5 World Superbike legends across 6 eras (1988-2026) and try to sweep all 24 races.

## How to Play

1. **Draft 5 legends** from any era (1988-95 / 1996-02 / 2003-09 / 2010-15 / 2016-21 / 2022-26)
2. **Mix eras for era synergy** — picking multiple drivers from the same era grants +1.5 OVR per extra driver beyond the first
3. **Race 24** — 12 rounds × 2 races each, all on real WSBK circuits (Phillip Island, Barcelona, Assen, Misano, Donington, Most, Cremona, Magny-Cours, Jerez, Portimão, Jerez finale)
4. **Win all 24** = "🏆 UNDEFEATED — 24-0 LEGEND!"
